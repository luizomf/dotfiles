# Pi Coding Agent configuration

The installer links static configuration from `pi/agent/` to `~/.pi/agent/`.
Credentials, sessions, trust decisions, generated resources, and machine-specific
model settings remain local and must not be committed.

Skills and extensions are maintained separately in
[omskills](https://github.com/luizomf/omskills) and
[ompi](https://github.com/luizomf/ompi).
